# NL-TECH video engine

- `codevid.py`: coding walkthrough videos (editor + terminal, human-speed typing, AI voiceover, captions, NL-TECH watermark).
  `python3 codevid.py ../scripts/<spec>.py out.mp4` (add `--stills` for a preview contact sheet).
- `../byte/`: Byte character explainers (X vs Y videos).
- Voice: Kokoro `am_michael` (model downloads automatically to ~/.cache/kokoro).
- Style rules: no transition whoosh; 3–6 min main videos; captions on everything.
